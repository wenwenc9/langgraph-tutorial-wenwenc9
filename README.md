# 二、环境设置

1、安装UV
```bash
pip install uv
```

2、创建python环境
```bash
uv venv --python=3.13
```

3、激活虚拟环境
```bash
.venv\Scripts\activate
```

4、安装包 【使用清华源】
```bash
uv  sync  -i https://pypi.tuna.tsinghua.edu.cn/simple
```
